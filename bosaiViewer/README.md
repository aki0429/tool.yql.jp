# DeckSpace / bosaiViewer

SitDeck のように、複数のWeb画面を一つの作業デスクに並べて監視できる静的Webアプリです。ビルドや追加ライブラリは不要で、`index.html` を配信すれば動作します。

## 主な操作

- 左のライブラリから内蔵ウィジェットやサイト内ツールを選択中のペインに表示
- `Window Capture` から、OSの共有ダイアログで選択したアプリウィンドウや画面を表示
- `左右分割` / `上下分割` で任意の深さまで分割し、境界線をドラッグしてサイズ変更
- タイトルバーを別ペインへドラッグして表示内容を入れ替え
- `+ サイト` から任意の `https://` URL または同一サイト内の相対パスを追加
- タイトルバーの `↗` でフローティング窓化し、移動・リサイズ・最大化・再ドック
- Windows 11 / macOS / Ubuntu / Browser 風のウィンドウ外観を選択
- 複数デスクとテンプレートを作成し、配置・メモ・URLをブラウザの `localStorage` に自動保存

## 表示できるサイトについて

外部サイト側が `X-Frame-Options` または CSP の `frame-ancestors` で埋め込みを禁止している場合、そのページはウィンドウ内に表示できません。ウィンドウ上部の `別タブ` リンクで直接開けます。

ネイティブアプリは `Window Capture` によるユーザー許可済みの画面共有として表示できます。画面共有APIは通常、HTTPS配信または `localhost` での表示時に利用できます。別PC上のアプリを取り込む場合は、別途リモート表示用のWebページ等が必要です。

## ファイル

- `index.html`: アプリ画面とダイアログ
- `styles.css`: ダッシュボード、ペイン、OS風ウィンドウ外観
- `app.js`: 分割レイアウト、浮動窓、サイト追加、保存処理
