# RiverCam Alert Recorder

気象庁の市区町村別警報を監視し、大雨警報（レベル3相当）以上の地域にある rivercam 画像を保存します。警報が大雨注意報（レベル2相当）以下へ下がるか解除されるまで継続します。

大雨は、大雨注意報=2、大雨警報=3、大雨特別警報=5として扱います。土砂災害は、土砂災害注意報=2、土砂災害警報=3、土砂災害危険警報（土砂災害警戒情報）=4、土砂災害特別警報=5、解除時=発表なしとして扱います。複数が同時発表された場合は最も高いレベルで保存を判定し、名称は併記します。気象庁の「警戒レベル」と個々の防災情報は完全な1対1ではないため、避難判断には使用しないでください。

## 保存構造

`Main/市区町村名/カメラ名/YYYY-MM-DDTHH-MM-SS_L3.avif`

## 起動

1. `config.example.json` を `config.json` にコピー
2. `npm start`
3. `http://サーバーIP:8787/` を開く

Node.js 20以上とffmpeg/ffprobeを使用します。既定では対象カメラを10分間隔で取得し、最大幅960px（小さい画像は拡大しない）、Lanczos縮小、libaom-av1による非可逆AVIFへ再エンコードして保存します。CRF 46から開始し、元画像より容量が増える場合はCRF 50、52および解像度を段階的に下げる適応圧縮です。変換後はffprobeでAV1コーデック・AVIFコンテナ・解像度を検証し、画像は7日間保持した後に自動削除します。既存WebPは引き続き閲覧できます。ビューアーでは選択したカメラ・日付の画像から、1秒あたり1～10枚を指定してMP4を書き出せます。`npm run build:index` で閲覧用索引を手動再生成できます。

## 常駐化（systemd）

`rivercam-alert-recorder.service.example` を編集し `/etc/systemd/system/rivercam-alert-recorder.service` に置き、`systemctl enable --now rivercam-alert-recorder` を実行してください。

このプロジェクトはWebサーバーへアップロードせず、指定Node.jsマシンだけで動かしてください。画像取得・再保存について国土交通省「川の防災情報」の利用条件を確認してください。
